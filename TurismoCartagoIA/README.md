# TurismoCartago_IA

Proyecto de inteligencia artificial para recomendar sitios turísticos de Cartago según intereses del usuario y presupuesto disponible.

## Estructura

- `data/`: dataset con sitios turísticos
- `src/`: código fuente del proyecto
- `graficos/`: visualizaciones generadas
- `tests/`: pruebas del sistema

## Ejecución

```bash
pip install -r requirements.txt
python src/main.py
```

## Descripción

Este proyecto carga datos turísticos, realiza un análisis exploratorio básico y recomienda lugares según la preferencia del usuario.
