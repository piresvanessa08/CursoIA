# Parcial 1 - Inteligencia Artificial - Grupo 01

## 1. Descripción del proyecto

Este proyecto corresponde al primer parcial de la asignatura Inteligencia Artificial.

Se realiza un análisis exploratorio de datos de fincas cafeteras de la región de Cartago, utilizando Python, NumPy y Matplotlib.

El conjunto de datos contiene información sobre:

- Finca
- Hectáreas
- Producción en kg
- Altitud en metros sobre el nivel del mar
- Variedad de café

## 2. Tecnologías utilizadas

- Python 3.12
- NumPy
- Matplotlib
- Docker
- Docker Compose
- Git y GitHub
