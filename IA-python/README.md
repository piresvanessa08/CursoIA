# Propuesta de Proyecto: Optimización de Cultivos en Cartago

## Problemática
Los agricultores de Cartago necesitan saber cuáles cultivos son más rentables y productivos según la cantidad de hectáreas sembradas para tomar mejores decisiones de siembra.

## Datos
- **Información requerida:** Nombre del cultivo, hectáreas sembradas, toneladas producidas y precio por tonelada.
- **Fuente:** Se utilizará un archivo CSV simulando datos abiertos de la Alcaldía de Cartago o el Ministerio de Agricultura.

## Objetivo
Desarrollar un sistema básico en Python que analice el rendimiento agrícola y recomiende el cultivo más eficiente usando estadísticas básicas.

## Tecnologías
- Python (Listas, Diccionarios, Funciones).
- Librerías futuras: Pandas para análisis de datos.
